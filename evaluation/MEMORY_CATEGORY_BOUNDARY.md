# Consequent Memory Category Boundary — FROZEN v0.1

Consequent is **not generic memory infrastructure**. It is a competitive memory-formation and evaluation protocol.

## Governing distinction

**STORED ≠ RECALLED ≠ INFLUENTIAL ≠ BENEFICIAL**

Miners transform specific prior execution experience into bounded, provenance-linked Behavioral Memory Patches (BMPs). Validators reward those patches only when paired evaluation on concealed future tasks shows beneficial behavioral influence.

Consequent does not primarily provide storage, retrieval, context compression, a stateful-agent runtime, or reusable executable skills.

## Engram boundary

Engram is persistent execution-memory infrastructure: preserve/reconstruct experience and influence provenance across runtimes. Consequent is the economic optimization layer: compete over what should be learned from experience and settle value by measured future consequence.

Any architecture that moves the commodity away from execution-derived memory evaluated by future causal utility requires an explicit category-boundary revision.
